# 🗺️ Қазақ жеріндегі реформалар — Интерактивті Mind Map

**XVIII–XIX ғасырлардағы Ресей империясының Қазақстандағы реформалары**

XMind / EdrawMind / MindManager стиліндегі толық интерактивті, төрт деңгейлі тармақталған схема. Қазақстан тарихы пәні бойынша мектеп курсына, ҰБТ және ЖОО бағдарламаларына сәйкес дайындалған.

🌐 **Live Demo:** https://zhalgasbaevaaaa-create.github.io/mindmapsarsenbayev/

---

## ✨ Ерекшеліктері

- 🌳 **Төрт деңгейлі құрылым** — Әр тармақта міндетті түрде 4 ұяшық
- 🌓 **Glassmorphism дизайн** — Қара-көк гласморфизм, градиент, көлеңкелер
- ✨ **Анимациялар** — Жұмсақ масштабталу, hover эффект, байланыс сызықтары
- 🖱️ **Drag & Pan** — Тінтуірмен/саусақпен сүйреу
- 🔍 **Zoom In/Out** — Дөңгелектеу, қалпына келтіру
- 🔎 **Іздеу** — Атау, қысқаша, сипаттама бойынша
- 📋 **Барлығын ашу/жабу** — Бір батырмамен
- 🗺️ **Миникарта** — Жалпы шолу
- 📑 **Detail panel** — Толық ақпарат, балалар тізімі
- 🖨️ **Экспорт** — PNG / PDF / SVG / JSON / Print
- ⌨️ **Пернетақта** — `/` іздеу, `+/-` zoom, `0` reset, `Esc` жабу
- 📱 **Толық адаптивті** — Телефон, планшет, ноутбук, 4K монитор

## 🚀 GitHub Pages-те жариялау

1. Репозиторий жасаңыз: `zhalgasbaevaaaa-create/mindmapsarsenbayev`
2. Барлық файлдарды push жасаңыз:
   ```bash
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/zhalgasbaevaaaa-create/mindmapsarsenbayev.git
   git push -u origin main
   ```
3. GitHub-та: **Settings → Pages → Source: `main` branch / root**
4. Бірнеше минуттан кейін мына URL-де қолжетімді:
   ```
   https://zhalgasbaevaaaa-create.github.io/mindmapsarsenbayev/
   ```

## 🛠️ Жергілікті іске қосу

```bash
# Python
python3 -m http.server 8000

# немесе Node.js
npx serve .
```

## 🎮 Басқару

| Әрекет | Әдіс |
|---|---|
| Тармақты ашу/жабу | Тармақты басу |
| Толық ақпарат | Тармақты таңдау (detail panel) |

| Zoom | Доңгелекпен немесе +/- пернелерімен |
| Іздеу | `/` пернесі немесе 🔍 батырма |
| Тармақтарды ашу/жабу | 🔽/🔼 батырмалар |
| Экспорт | ⬇️ батырма → PNG/PDF/SVG/JSON/Print |
| Reset | 🏠 батырма (zoom-reset) |
| Толық экран | ⛶ батырма |
